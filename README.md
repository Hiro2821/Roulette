# 継続日数ルーレット

何かを継続する日数を、ルーレットで決める Web アプリです。
HTML / CSS / JavaScript だけの静的アプリで、サーバー・外部API・ライブラリは不要、オフラインでも動作します。

## 使い方

- `index.html` をブラウザで開く（GitHub Pages で公開すれば iPhone のホーム画面にも追加できます）
- **SPIN** で抽選 → 結果が出たら「結果を確定する」でチャレンジ開始
- 右上の範囲ボタンから、最短日数・最長日数を変更（初期値 2〜7日、1日以上の整数、候補は最大60種類）
- 設定とチャレンジの状態は `localStorage` に保存されます

## 抽選の仕組み

1. 先に当選区画を一様乱数（`crypto.getRandomValues` ＋ 棄却サンプリングで剰余バイアスなし）で決定
2. 当選区画の中心から ±36% 以内の位置で止まるよう、停止角度を逆算
3. 加速 → 等速 → 三次イーズアウトの減速カーブで回転（アニメーションは結果に影響しません）

## テスト

```sh
node tests/logic.test.js
```

入力検証、抽選の均等性（χ²検定）、指針と当選区画の一致、回転カーブの連続性を検証します。

## GitHub Pages で公開する

リポジトリの **Settings → Pages → Build and deployment** で、Source を `Deploy from a branch`、Branch を `main` / `/ (root)` に設定します。


## 月間スケジュールモード
画面下のタブで「ルーレット」と「月間スケジュール」を切り替えます。

- 初期設定は最短2日・最長7日。月初→最初の実行日、実行日どうし、最後の実行日→月末のすべてが範囲内になるスケジュールだけを生成します。
- 月末から逆算して「最後まで有効に終えられる日」だけを候補にし、その中から乱数で選ぶため、やり直し・無限ループはありません。
- 対象年月（年・月・前後月・今月に戻る）、最短/最長間隔を変更できます。生成できない設定は理由と直し方を表示します。
- 「保存」で localStorage に保存します（キー: `keizoku-schedule:data:v1` / `keizoku-schedule:settings:v1` / `keizoku-app:mode:v1`）。ルーレットのデータには影響しません。

### テスト
```sh
node tests/logic.test.js
node tests/schedule.test.js
```

### 抽選演出
「スケジュールを生成」を押すと、実行日を1回ずつ抽選する演出が始まります（初回実行日 → 2回目 → … → 月末の最終判定）。

- 抽選結果は演出の開始前に確定し（`generateSchedule`）、`buildDrawSteps` が1回ずつの抽選（候補・当選日）に分解します。演出は乱数を引き直さず、その結果を表示するだけです。表示される候補は、最後まで条件を満たせる日だけです。
- 進捗（STEP n / N、抽選済み・残り、進捗バー）、カレンダーへの1日ずつの反映、完成演出（SCHEDULE COMPLETE）、対応端末での振動に対応しています。
- 「スキップ」で残りを即時表示、「中止」で途中経過を破棄します。抽選中は二重実行・設定変更・タブ切替ができません。完成までは何も保存されません（保存は完成後の「保存」で行います）。
- 「動きを減らす」設定では演出が短縮されます。

## 演出（光・カウントダウン・サウンド）
ルーレットの SPIN では、ボタン反応 → 周囲のゴールドの光 → 中央に光が集まる → 3・2・1 → 急加速 → 高速回転（外周の光の帯と残像）→ 自然な減速 → 停止（衝撃）→ 結果発表（一瞬の暗転・光の輪・粒子・数字のスケール）の順に進みます。

- **結果は必ず先に確定**します（`randomInt`）。停止角度は当選区画から逆算し、演出は結果を表現するだけです。演出中に乱数を引き直しません。
- **ニアミス演出**はルーレットでは「区画の端ぎりぎり（当選区画の内側）で止める」、月間スケジュールでは「当選日を通り過ぎて隣で止まり、戻る」という見た目だけの演出です。確率・結果には影響しません（`tests/logic.test.js` で検証）。
- **サウンド**は外部音源なしで Web Audio API により合成しています（開始・カウント・クリック・ニアミス・確定・結果・完成）。右上のスピーカーボタンから ON/OFF・音量・振動の切り替えができ、`localStorage`（`keizoku-app:fx:v1`）に保存されます。音を再生できない環境（非対応・ブラウザの制限）では何も鳴らさず、視覚演出だけで動作します。iOS では最初の操作（SPIN・生成ボタン）の中で音を有効化します。
- **スキップ**: 回転中、SPIN ボタンが「SKIP」に変わります（誤タップ防止のため開始約1秒後から）。結果は同じで、すぐに結果画面に進みます。
- **軽量化**: 「動きを減らす」設定では光・粒子・カウントダウンを省略します。論理コア数が少ない端末や、回転中にフレームが落ちた場合は、外周の光・残像・粒子を自動的に減らします。
