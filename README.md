# 継続日数ルーレット

何かを継続する日数を、ルーレットで決める Web アプリです。
HTML / CSS / JavaScript だけの静的アプリで、サーバー・外部API・ライブラリは不要、オフラインでも動作します。

## 使い方

- `index.html` をブラウザで開く（GitHub Pages で公開すれば iPhone のホーム画面にも追加できます）
- **SPIN** で抽選 → 結果が出たら「結果を確定する」でチャレンジ開始
- 右上の範囲ボタンから、最短日数・最長日数を変更（初期値 2〜7日、1日以上の整数、候補は最大60種類）
- 設定とチャレンジの状態は `localStorage` に保存されます

## 抽選の仕組み

1. 先に当選区画を一様乱数（`crypto.getRandomValues` ＋ 棄却サンプリングで剰余バイアスなし）で決定
2. 当選区画の中心から ±36% 以内の位置で止まるよう、停止角度を逆算
3. 加速 → 等速 → 三次イーズアウトの減速カーブで回転（アニメーションは結果に影響しません）

## テスト

```sh
node tests/logic.test.js
```

入力検証、抽選の均等性（χ²検定）、指針と当選区画の一致、回転カーブの連続性を検証します。

## GitHub Pages で公開する

リポジトリの **Settings → Pages → Build and deployment** で、Source を `Deploy from a branch`、Branch を `main` / `/ (root)` に設定します。
